รายการประกอบแบบมาตรฐาน กองออกแบบงานโยธา การไฟฟ้าส่วนภูมิภาค ฉบับปี 2568

⚠️ ยังไม่ได้ตั้งค่า API Key

ตั้งค่า Google Gemini API Key

✓ เว็บนี้ตั้งค่าให้ใช้งานผ่านระบบกลาง (Proxy) ไว้แล้ว ทุกคนใช้งานได้ทันทีโดยไม่ต้องกรอก API Key ของตัวเอง — เลือกโมเดลที่ต้องการแล้วกด "บันทึก" ได้เลย

API Key และโมเดลที่เลือกจะถูกบันทึกไว้ใน Browser ของเครื่องคุณเท่านั้น (Local Storage) ไม่ถูกส่งไปที่ใดนอกจาก Google โดยตรง

ขอ API Key ฟรีได้ที่ aistudio.google.com/apikey

ถ้าโมเดลที่เลือกเรียกไม่สำเร็จ ระบบจะลองโมเดลสำรองในรายการให้อัตโนมัติ
